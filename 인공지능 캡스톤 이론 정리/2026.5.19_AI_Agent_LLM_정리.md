## 1. AI Agent와 MCP 개요

### 1.1 에이전트(Agent)란?

- **에이전트**: 환경을 **지각(Perceive)** 하고, 그 지각에 따라 **행동(Act)** 하는 모든 것
- **AI 에이전트**: 인공지능 기술로 환경을 지각하고, 합리적 판단을 통해 목표를 달성하는 시스템

| 구분 | 인간 | AI 에이전트 |
|------|------|------------|
| 지각 | 오감 (시각·청각·후각·미각·촉각) | 센서 (카메라, 마이크, 온도 센서 등) |
| 행동 | 근육, 언어, 표정 등 | 액추에이터 (모터, 디스플레이, 스피커 등) |
| 목표 | 생존, 행복, 학습, 문제 해결 등 | 주어진 목표 달성 (최단 경로 탐색, 최적 추천 등) |

---

### 1.2 이전 LLM의 한계 — "갇혀 있는 천재"

- LLM은 매우 똑똑하지만 **학습된 데이터에 갇혀 있음**
- **행동 능력 부재**: 텍스트 생성은 가능하나 이메일 송신, 파일 수정, 코드 실행 등 실제 **행동**은 불가
- **해결책**: 에이전트 프로그램을 **외부 도구(Tools)** 와 연결

---

### 1.3 MCP(Model Context Protocol)란?

> AI를 위한 **범용 USB-C 포트**

- **정의**: AI 모델이 외부 데이터 소스·도구와 **안전하고 표준화된 방식**으로 통신할 수 있게 해주는 오픈 소스 프로토콜
- **개발**: Anthropic(Claude 개발사) 주도

#### MCP의 핵심 특징

| 특징 | 설명 |
|------|------|
| 표준화 (Standardization) | MCP 서버를 한 번만 구축하면 MCP를 지원하는 모든 AI 에이전트와 즉시 연결 가능 |
| 보안 (Security) | 사용자가 권한을 통제하고 안전하게 데이터를 주고받을 수 있는 환경 제공 |
| 확장성 (Scalability) | 로컬 파일, 사내 DB, 외부 API 등 무한한 종류의 도구를 AI 에이전트에 연결 가능 |

#### 과거 vs 현재 비교

- **과거**: 각 도구마다 개별 맞춤형 API 개발 필요 → **N:N 구조** (복잡)
- **현재**: 단 하나의 범용 프로토콜로 모든 도구 통제 → **1:N 구조** (단순)

---

### 1.4 MCP 작동 원리 — 3자 협력 구조

| 구성 요소 | 설명 | 예시 |
|-----------|------|------|
| **MCP 호스트 (Host)** | AI 에이전트 프로그램이 실행되는 환경 | Claude Desktop, Cursor IDE, Manus AI |
| **MCP 클라이언트 (Client)** | 호스트 내부에 존재하며 서버와 통신 담당 | client.py |
| **MCP 서버 (Server)** | 외부 도구·데이터 소스를 감싸고 요청을 실행해 결과 반환 | Slack, Gmail, DB 등 |

## 2. 클로드 커넥터 개요

### 2.1 커넥터란?

- **"대화만 하는 AI"** → **"업무 도구를 실제로 다루는 AI"** 로 확장하는 연결층
- **MCP를 활용**해 외부 서비스(Notion, Gmail, Google Calendar 등)와 직접 연결
- 단순 문서 참조를 넘어 **페이지 생성·일정 등록·메일 초안 작성** 등 실제 작업 수행
- 복잡한 설정 없이 몇 번의 클릭으로 연결하는 **노코드(No-code) 솔루션**

---

### 2.2 커넥터 연결 방식

| 방식 | 설명 |
|------|------|
| **공식 인티그레이션 (Integrations)** | 일반 사용자를 위한 노코드 솔루션. OAuth를 통해 간편하게 연결 |
| **MCP (Model Context Protocol)** | 개발자를 위한 오픈 소스 표준. 로컬 파일 시스템 및 커스텀 워크플로우 구축에 최적 |

> **OAuth(Open Authorization)**: 비밀번호 노출 없이 Google·Facebook 등 서비스의 권한을 다른 앱에 안전하게 부여하는 **개방형 표준 인증 프로토콜**

---

### 2.3 커넥터 활용 필요성

- **정확하고 실용적인 답변**: 여러 앱을 오가며 실제 자료를 기반으로 응답
  - 예: "이 회의 관련 메일 요약해줘" → Gmail 연동 시 실제 메일 내용 기반 요약
- **업무 자동화**: 반복 업무를 하나의 흐름으로 처리
  - 예: 노션 회의록 작성 → Gmail 초안 작성 → Google Calendar 일정 등록

---

### 2.4 Gmail 커넥터 설정 방법

1. 커넥터 메뉴 → `+` 버튼 → `gmail` 검색
2. Gmail 항목에서 `+` 클릭
3. Google 계정 로그인 (OAuth 인증)
4. 참조 항목 선택 후 `계속` 클릭
5. **도구 권한** 설정:
   - **읽기 전용 도구**: `항상 허용` (자동 실행)
   - **쓰기/삭제 도구**: `승인 필요` (사용자 확인 후 실행)

## 3. 클로드 커넥터 활용

### 3.1 Gmail 활용

#### 기초 활용 예시

```
오늘 온 gmail에서 중요한 메일부터 정리해 줘
내 지메일에서 최근 5일간 메일 중 중요 메일 요약해줘
```

#### 사례 1: 학생 문의 메일 답장

**활용 흐름**:
1. `최근 3~5일간 학생 문의 메일 내용 정리해줘`
2. `답변 초안 작성해 줘`
3. 내용 수정 후 `임시 저장`
4. Gmail에서 임시 메일 열어 `보내기` 클릭

> **참고**: 현재 Claude 커넥터는 메일 직접 전송(send_email) 불가 → 임시 저장 후 수동 발송

---

### 3.2 Google Calendar 활용

#### 사례: 카드 청구 금액 납부 마감일 자동 등록

**프롬프트 예시**:
```
내 Gmail에서 최근 롯데카드 청구서 이메일을 검색해줘.
이메일에서 청구 금액과 납부 마감일을 추출한 뒤,
Google 캘린더의 해당 마감일에 "롯데카드 납부: [금액]원" 형식으로 일정을 등록해줘.
```

**결과**: Gmail 검색 → 금액/날짜 추출 → Calendar 자동 등록 ✅  
**제한**: 첨부 파일(PDF) 직접 읽기는 미지원 → 본문 텍스트만 분석

---

### 3.3 Google Drive 활용

#### 사례 2: 메일 첨부파일 구글 드라이브 저장

```
오늘 온 지메일 중 첨부 파일이 있는 메일 알려줘
나의 구글 드라이브에 '[오늘날짜] Gmail 첨부파일' 폴더를 만들고 저장해줘
```

#### 사례 3: 채팅 결과를 구글 드라이브에 저장

```
위 내용을 내 구글 드라이브에 \claude\connector 폴더를 만들어 저장해줘
```

#### 다양한 Google Drive 활용 아이디어

**파일 탐색/검색**
- "최근에 수정한 파일 5개 보여줘"
- "'머신러닝' 키워드가 포함된 문서 검색해줘"

**문서 읽기/분석**
- "드라이브에 있는 논문 초안 읽고 피드백 줘"
- "강의계획서 파일 불러와서 주차별 일정 표로 정리해줘"

**문서 작성/업로드**
- "방금 작성한 강의 노트를 드라이브에 저장해줘"

**다른 커넥터와 조합**
- "드라이브 강의자료 읽어서 → Gmail로 학생들에게 요약 발송"
- "드라이브 문서 읽어서 → Google Calendar에 마감일 일정 추가"

---

### 3.4 Notion 활용

#### 사례 4: 질의 결과를 노션에 저장

**연결 방법**: 커넥터 → Notion 선택 → 워크스페이스 선택 → `계속하기`

**프롬프트 예시**:
```
너 claude의 기능 중에 2026년에 새로이 추가된 기능에 대해 정리하고 설명해 줘
위 내용을 나의 노션에 페이지 [2026 클로드 추가된 기능]를 만들어 저장해 줘
```

### 3.5 카카오톡(PlayMCP) 연결

#### 연결 방법

1. [https://playmcp.kakao.com](https://playmcp.kakao.com) 접속 → 카카오 계정 로그인
2. '카카오톡 나와의 채팅방' MCP 검색 → 도구함에 추가
3. Claude 커넥터에서 `PlayMCP` 검색 → `+` 클릭
4. 브라우저 연결 화면에서 `모두 동의 후 계속하기` (인증 3~4분 소요)

#### 활용 예시

```
카톡 나챗방에 연결되었는지 확인해 줘
'안녕!' 보내줘
위의 내용을 정리해서 나에게 보내 줘
```

---

### 3.6 Claude in Chrome 활용

#### 설치 방법

1. [Chrome 웹 스토어](https://chromewebstore.google.com/) 접속 → "Claude" 검색
2. `Add to Chrome` 클릭 → 설치
3. 퍼즐 조각 아이콘 → Claude 옆 압정 아이콘 클릭하여 툴바에 **고정**
4. Claude 계정으로 로그인 → 권한 허용

#### 주요 기능

| 기능 | 설명 |
|------|------|
| 웹 자동화 | 웹사이트 탐색, 버튼 클릭, 폼 작성 자동화 |
| 워크플로우 녹화 | Claude에게 작업 방식을 가르쳐 반복 작업 자동화 |
| 주요 플랫폼 내장 지원 | Slack, Gmail, Google Calendar, GitHub 등 기본 사용법 내장 |
| Claude Code 통합 | 코드 작성 후 브라우저에서 바로 테스트·디버깅 |

#### 활용 사례

- **웹 페이지 정리**: 현재 탭 내용을 사이드 패널에서 즉시 요약·분석
- **검색 후 접속**: "기초통계학을 파이썬으로 이해하는 미국 사이트 알려 줘" → 자동 접속
- **프레젠테이션 자동 생성**: 페이지 정리 후 Gamma 등에 자동으로 접속하여 PPT 생성

> **제한**: 금융 사이트(네이버 페이 증권 등)는 민감 카테고리(sensitive site)로 분류 → 접근 불가

```
LLM 단독         →  "머리 좋은 똑똑이" (행동 불가)

```
