## Section 1. claude.ai 개요

### 클로드(Claude) AI란?

Anthropic이 개발한 생성형 AI로, 2021년 OpenAI 전 부사장 **다리오 아모데이(Dario Amodei)**가 설립한 회사에서 만들었다.

- 이름의 유래: 정보 이론의 아버지 **Claude Shannon**에서 영감
- 핵심 철학: **"안전하고 정확한 AI"**
  - AI 기술의 잠재적 위험성을 인식하고, AI가 인간에게 신뢰할 수 있는 도구로 자리 잡도록 하는 것을 목표
  - AI 기술이 보다 윤리적이고 신뢰할 수 있는 방향으로 나아가고자 하는 Anthropic의 철학을 반영

---

### 클로드 주요 특징

| 특징 | 설명 |
|------|------|
| **윤리적 AI 원칙** | 사용자의 요청에 대해 안전하고 책임 있는 방식으로 응답하도록 설계 |
| **Artifacts** | 대화 중 코드, 문서, 웹사이트를 실시간으로 생성하고 미리보기 가능 |
| **200K 토큰 컨텍스트 윈도우** | 약 15만 단어(소설 한 권 분량)를 한 번에 처리 |
| **환각(Hallucination) 최소화** | 모르는 것은 모른다고 솔직하게 답변 |
| **Extended Thinking** | 복잡한 문제를 단계별로 사고하는 심층 추론 기능 |

### 기본 인터페이스 구성

**왼쪽 메뉴:** 새 채팅, 프로젝트, 아티팩트, 로그인 계정 등

**가운데 대화창:**
- 질문을 입력하는 텍스트 입력창
- `+` 버튼: 파일 업로드 선택 (파일/사진, 스크린샷, Google Drive, GitHub, 스킬, 커넥터, 웹 검색, 스타일 사용 등)
- 모델 선택 드롭다운

### Claude 모델 비교

#### 모델 명칭의 문학적 의미

| 모델 | 문학적 의미 | 기술적 의미 | 특징 |
|------|-----------|-----------|------|
| **Opus** | 대작 | 최고 성능 모델 | 복잡한 문제 해결 |
| **Sonnet** | 정형시 | 균형형 모델 | 범용 작업 |
| **Haiku** | 짧은 시 | 경량 모델 | 빠른 응답 |

**활용 목적에 따른 선택:**
- 복잡, 정밀성 → **Opus**
- 균형 → **Sonnet**
- 간결, 속도 → **Haiku**

#### 모델 상세 비교표

| 구분 | Opus 4.6 | Sonnet 4.6 | Haiku 4.5 |
|------|----------|------------|-----------|
| 모델 유형 | 최고급 대형 모델 | 범용 중간 모델 | 경량 고속 모델 |
| 주요 목표 | 최고 정확도·추론 | 성능-속도 균형 | 빠른 응답·저비용 |
| 추론 능력 | 매우 높음 | 높음 | 보통 |
| 코드 생성 | 매우 우수 | 우수 | 기본 수준 |
| 긴 문서 처리 | 최상 | 우수 | 제한적 |
| 정확도 | 최고 수준 | 높은 수준 | 중간 수준 |
| 창의성 | 매우 높음 | 높음 | 보통 |
| 응답 속도 | 느림 | 보통 | 매우 빠름 |
| 비용 | 매우 높음 | 중간 | 낮음 |
| 처리량 | 낮음 | 중간 | 높음 |
| 적합한 작업 | 연구·논문·고급 분석 | 교육·실무·개발 | 챗봇·FAQ·실시간 처리 |
| 추천 사용자 | 연구자·전문가 | 일반 사용자·개발자 | 서비스 운영자 |

> **확장 사고(Extended Thinking):** 추론을 출력과 분리하여, 응답 전에 내부에서 충분히 생각할 공간을 부여하는 메커니즘. 복잡한 작업에 유용.

**Free 플랜 주요 기능:** 웹·iOS·Android·데스크톱 채팅, 코드 생성 및 데이터 시각화, Slack 및 Google Workspace 연결, 복잡한 작업을 위한 확장 사고, 내장 웹 검색

**Max 플랜 추가 기능:** Pro 대비 최대 20배 더 많은 사용량, Claude 고급 기능 조기 액세스, 트래픽이 많은 시간대의 우선 액세스, PowerPoint의 Claude

## Section 2. claude.ai 기본 활용

### 설정 (개인 맞춤화)

**설정 경로:** 설정 > 일반 > 프로필

개인 맞춤 설정 예시:
```
신원 / 역할 — 인공지능소프트웨어학과 교수
전문 분야 — ML/DL, NLP, 인공지능 교육, 프로그래밍 언어, 바이브 코딩
주요 사용 목적 — 강의 자료 및 수업 준비, 연구 논문 작성·검토, 코드 작성·디버깅, 학생 질문 답변 초안 작성, 금융·주식 투자 리서치
응답 스타일 — 학술적·정확한 표현 우선, 전문 지식을 전제하고 기초 설명 생략, 또는 학생에게 설명할 수 있는 쉬운 설명
```

> Claude가 응답에서 고려해야 할 개인 맞춤 설정을 입력하면, Anthropic의 가이드라인 내에서 모든 대화에 적용된다.

### 프로젝트

관련된 대화들을 하나의 작업 공간으로 묶어서 관리하는 기능. 무료 사용자는 최대 5개의 프로젝트 생성 가능.

**핵심 구성 요소:**

**① 지속적 메모리 (Persistent Context)**
- 프로젝트 내 모든 대화에서 공유되는 System Prompt 설정 가능
- 매 대화마다 배경 정보를 반복 입력할 필요 없음
- 예: "이 프로젝트는 NLP 강의 자료 개발용이며, 수강생은 학부 3학년입니다"

**② 파일 업로드 및 공유**
- PDF, 코드, 문서 등을 프로젝트 레벨에서 업로드하면 모든 대화에서 참조 가능
- 논문, 강의계획서, 데이터셋 명세서 등을 한 번 업로드 후 반복 활용

**③ 대화 분류 및 정리**
- 주제별로 대화를 프로젝트로 구분 (예: 강의 준비 / 연구 논문 / 코드 디버깅)
- 이전 대화 내용 추적 및 재참조 용이

---

### 프로젝트 지침

특정 프로젝트의 구체적인 맥락과 요구 사항을 이해하는 데 도움을 주며, 일관된 맥락을 유지해야 할 때 특히 유용하다. 지침은 해당 프로젝트 내의 채팅에만 적용된다.

**프로젝트 지침을 사용하는 경우:**
- 프로젝트별 맥락을 제공할 때
- 특정 워크플로에 대한 지침을 설정할 때
- 특정 작업 세트에 대한 요구 사항을 설정할 때
- 클로드가 프로젝트 내에서 맡아야 할 역할이나 관점을 정의할 때

### 아티팩트(Artifacts)

Claude가 대화창 옆 별도 패널에 독립적으로 렌더링되는 결과물을 생성하는 기능.

**지원 파일 타입:**

| 타입 | 확장자 | 용도 |
|------|--------|------|
| Markdown | `.md` | 보고서, 문서, 강의 노트 |
| HTML | `.html` | 웹 페이지, 인터랙티브 UI |
| React | `.jsx` | 동적 컴포넌트, 대시보드 |
| SVG | `.svg` | 다이어그램, 일러스트 |
| Mermaid | `.mermaid` | 플로우차트, ER 다이어그램 |
| PDF | `.pdf` | 인쇄용 문서 |

**아티팩트 핵심 특징:**
- **렌더링 패널 분리:** 대화창과 결과물이 좌우로 분리되어 표시 → 코드 설명과 결과를 동시에 확인 가능
- **반복 수정(Iterative Editing):** "표 컬럼 추가해줘", "색상 바꿔줘" 같은 후속 요청으로 점진적 개선 가능
- **다운로드 및 복사:** 생성된 결과물을 바로 다운로드하거나 클립보드로 복사 가능

---

### 아티팩트 타입별 활용

#### JSX (JavaScript XML, React Component)
- `.jsx` 확장자로 저장
- React 기반의 인터랙티브 UI 컴포넌트를 렌더링
- 인터랙티브 시뮬레이터, 계산기, 대시보드, 데이터 시각화(recharts 등), 학생 실습용 인터페이스에 활용

#### SVG (Scalable Vector Graphics)
- `.svg` 확장자
- XML 기반의 벡터 그래픽으로 대화창에 인라인 렌더링
- 구조 다이어그램, 흐름도, 메모리 레이아웃 시각화, 개념 설명용 일러스트레이션에 활용

#### Mermaid
텍스트 기반으로 다이어그램을 생성하는 JavaScript 라이브러리:
- `flowchart` — 알고리즘 흐름, 의사결정 과정
- `sequenceDiagram` — API 통신, 클라이언트-서버 상호작용
- `classDiagram` — OOP 설계, UML
- `erDiagram` — 데이터베이스 스키마
- `stateDiagram-v2` — 오토마타, 상태 머신
- `gitGraph` — 브랜치 전략 설명

### "사용자 지정" 핵심 기능

**스킬:** 반복 작업을 구조화하는 지침 묶음 기능. 어려운 프롬프트 설계를 자동으로 수행.

## Section 3. 스킬 개요

### 스킬이란?

> **커스텀 스킬 = AI에게 전문가 핸드북 주입**
> SKILL.md 파일 하나로 → Claude가 상황에 맞게 자동 호출
> 프롬프트를 '기억'하는 구조가 아니라 ← 필요할 때 불러오는 시스템

반복 가능한 작업 또는 워크플로를 위한 구조화된 지침을 미리 등록해 자동으로 적용하는 기능.

**정의:**
- 특정 작업을 수행할 때 참조하는 구조화된 지식·절차 문서
- 특정 작업 수행을 위한 규칙과 형식 정의
- 파일 시스템에 저장되어 있다가 관련 요청이 들어올 때 클로드의 컨텍스트에 로드
- 특정 업무의 표준 운영 절차(SOP: Standard Operating Procedure)를 미리 주입해두는 방법

**특징 및 장점:**
- 좋은 프롬프트의 반복 작성에서 벗어남 → 시간 절약 및 효율 향상, 토큰 비용 절감 효과
- 일관된 출력 품질을 유지하는 것이 핵심 → 표준화된 결과 생성, 작업 품질의 일관성 확보

---

### 스킬 작동 원리

**대화 시작 시:**
- 스킬의 메타데이터(`name`, `description`)만 먼저 로드
- 관련 요청이 들어오면 전체 내용을 불러와 실행

**점진적 로딩:**
- 컨텍스트 과부하를 방지
- 활성화된 스킬만 선택적으로 사용해 응답 속도를 높임

**자연어로 워크플로나 지침을 정의:**
- 코딩 없이도 자연어로 커스텀 스킬 생성 가능
- 이미 만들어진 스킬 활용 가능

---

### SKILL.md (핵심 파일, 필수)

스킬의 모든 것이 시작되는 파일로, 두 부분으로 구성된다.

#### ① YAML 프론트매터 (Front Matter) — 항상 메모리에 상주
자동 로드 판단 기준. 이 부분만 보고 "이 요청에 이 스킬을 쓸지" 판단한다.
- `name`: 스킬 식별자
- `description`: 트리거 조건(언제 자동으로 불러올지) + 스킬이 하는 일(무엇을 하는지)

```yaml
---
name: skill-creator
description: 새로운 스킬을 생성하고, 기존 스킬을 수정·개선하며,
스킬 성능을 측정합니다. 사용자가 스킬을 처음부터 만들거나,
수정·최적화하거나, 평가 실행(evals)으로 테스트하거나, 분산
분석으로 벤치마킹하거나, 트리거 정확도를 높이기 위해 스킬
설명을 최적화할 때 사용합니다.
---
```

> **YAML(YAML Ain't Markup Language):** 사람이 읽기 쉬운 데이터 포맷. 애플리케이션 설정 파일에 주로 사용.

#### ② 본문 (Markdown) — 트리거 시 로드
실제 작업 절차, 규칙, 템플릿을 담는다.
- 명확히 무엇을 어떻게 할지 기술
- **500줄 이하** 권장
- 상세 내용은 `references/`로 분리하고 포인터만 기재

---

### 스킬 폴더 구조

```
skill-name/
├── SKILL.md          # 핵심 파일 (필수)
├── references/       # 상세 참조 문서 (선택)
├── scripts/          # 반복·자동화 실행 파일 (선택)
└── assets/           # 정적 파일, 템플릿 등 (선택)
```

**로컬 저장 위치:** `~/.claude/skills/`

| 폴더 | 역할 |
|------|------|
| `references/` | SKILL.md 본문이 포인터로 가리키는 상세 참조 문서. 필요할 때만 로드되므로 분량 제한 없음 |
| `scripts/` | 반복·자동화 작업용 실행 파일(Python 등). 스킬 성능 측정용 eval 스크립트도 여기에 위치 |
| `assets/` | 출력물 생성에 필요한 정적 파일. 템플릿, 폰트, 아이콘 등 |

---

### SKILL.md 샘플 구조

```markdown

description: 새로운 스킬을 생성하고 기존 스킬을 수정 및 개선하며, 스킬 성능을 측정하는 도구이다.

# 스킬 생성기 (Skill Creator)

이 스킬은 새로운 스킬을 만들고 반복적으로 개선하기 위한 것이다.

## 전체 프로세스
- 스킬의 목적과 동작 방식을 정의한다
```

## Section 4. 스킬 활용

### 스킬 직접 생성 절차

1. **반복 작업 하나 선정** — 반복성, 규칙성, 일관성이 중요한 작업을 스킬 후보로 선정
2. **스킬을 위한 프롬프트 작성** — "스킬의 목적"을 기술하면서 "추천 스킬 요청 프롬프트" 재작성 요청
3. **클로드의 질의에 응답** — 스킬 작성에 필요한 몇 개의 질의(객관식)에 응답
4. **스킬 생성 과정을 보면서 기다림** — 작업 과정이 표시됨
5. **생성된 스킬 확인:**
   - 트리거 키워드가 `description`에 있는지 확인 (자동 호출이 되려면 Claude가 자연어 요청과 스킬 설명을 잘 매칭해야 함)
   - 본문에서 규칙, 예시, 금지사항 등 확인 (예시가 있으면 결과 품질이 더 안정적)
6. **수정이 있으면 다시 요청**
7. **생성 후 테스트** — 자연스러운 문장으로 호출해 결과 확인
8. **필요하면 다시 요청**

### 스킬 생성을 위한 프롬프트 정제 예시 (주식 추천 스킬)

**스킬 생성 요청 프롬프트 예시:**
```
다음처럼 "주식 추천에 관한 스킬"을 요청하려고 해, 먼저 다음 '스킬 요청 문장'을 적절히 수정해 줘

• 목적: 최근 주식 시황을 분석해서 실적이 좋을 섹터를 선정해 수혜가 예상되는
  관련 국내 ETF와 주식 종목을 각각 5개 정도 소개해 줘
• ETF는 과거 실적이 좋으며 수수료가 낮은 것으로 추천해 줘
• 특히 단기(1-3개월), 중기(6-12개월), 장기(1년 이상)로 나누어서 각각 종목 5개씩 설명해줘
```

**정제된 스킬 요청 문장 (Claude가 제안):**
```
최근 주식 시황을 분석하여 유망 섹터를 선정하고, 해당 섹터의 수혜가 예상되는
국내 ETF 및 개별 주식 종목을 투자 기간별로 추천해 주세요.
분석 기준:
• 최신 글로벌·국내 거시경제 지표, 실적 발표, 산업 트렌드를 반영하여 유망 섹터를 선정
• 선정 섹터별로 국내 상장 ETF(과거 수익률 우수 + 보수율 낮은 순 우선)와 개별 주식 종목 각 5개 추천
투자 기간별 구분 (각 5종목):
• 단기 (1~3개월): 모멘텀·이벤트 드리븐 관점
• 중기 (6~12개월): 실적 턴어라운드·섹터 사이클 관점
• 장기 (1년 이상): 구조적 성장·밸류에이션 관점
각 종목 설명 항목: 종목명·티커, 추천 근거, 주요 리스크, 목표가 또는 기대 수익률 범위
```

### 스킬 등록과 활성화

1. 스킬 생성 후 **스킬 저장** 버튼 클릭
2. 사용자 지정 > 스킬 메뉴에서 등록된 스킬 확인
3. 스킬 **활성화 토글** ON/OFF
4. 이후 자연스러운 문장으로 트리거 테스트

**트리거 조건 예시 (주식 추천 스킬):**
- "주식 추천", "종목 추천", "ETF 추천", "투자 추천" 요청
- "요즘 어떤 주식이 좋아?", "지금 시장 어때?" 등 시황 기반 종목 문의
- "단기/중기/장기 투자할만한 종목", "섹터 분석" 요청
- "국내 ETF 추천", "미국 ETF 추천", "코스피 ETF", "테마 ETF" 등 ETF 관련 문의

> 스킬 파일은 Claude 설정의 Skills 메뉴에서 업로드하면 바로 사용 가능.
